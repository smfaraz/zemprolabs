## Quick Start

### 1. Prerequisites
- **Node.js** (v18.0.0 or higher recommended)
- **npm** (v9.0.0 or higher)

### 2. Installation
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the port output in your terminal, e.g. 3001) in your browser.

### 4. Type Verification
```bash
npx tsc --noEmit
```

### 5. Production Build
```bash
npm run build
```
